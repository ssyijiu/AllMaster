# 像素探头

适用：小像素大头头像、角色探头系列；共用画法，角色身份独立填写。将下段放入 `art_style`，用当前角色参考图填写 `game_knowledge` 和 `subject_description`。`composition` 只补本次画布与站位，保持探头比例。配套 `pixel_style` 使用 `pixel-peek-pixels.md`，背景沿用生图参数。

WorkBuddy 使用本模板调用 `scripts/val_perler.py generate` 时，传入 `--boards 36 52 78`，预生成图纸最大78格；默认展示档通过 `--default-size 36`、`52` 或 `78` 选择。此流程仅用 `--boards` 指定尺寸集合，省略 `--target-size`（该参数会重建集合并附带相邻规格）。本段是调用说明，仅将下方「生图描述」正文传入 `art_style`。

## 生图描述

画成迷你游戏像素头像：正面探头，头部占图案高度约85%，下沿仅露一条窄领口，左右各一颗小圆团手。每颗手用约2×2至3×3方块表达，手指与手臂合并，身体被下沿遮住。完整保留头顶与侧边轮廓，四周留空；下沿是图案的结束位置，不额外画桌子或栏杆。

视觉中心是发型剪影和双眼。头发保留当前角色的发际线、分缝、束发位置、主色和标志配饰，简化为少量连贯阶梯色块，避免统一成同一种发型。人类眼睛用左右两组约3×4方块的瞳色、深色上眼线和一小格高光表达；鼻子一小点，腮红各一小块，嘴可省略。脸部整块平涂，发色与肤色按角色参考归属。

机械、面罩或无常规五官的角色，以头壳剪影与标志屏幕、面罩或发光纹路替代人类眼睛和皮肤；保留同样的探头构图，手团用对应材质主色。参考图只决定身份和外观，姿态重新组织成探头头像。
