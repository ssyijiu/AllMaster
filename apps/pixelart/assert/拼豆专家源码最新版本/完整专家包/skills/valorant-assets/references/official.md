# 官网取图

## 入口与定位

端游资料入口：`https://val.qq.com/game-data.html?pageType=1`；手游英雄入口：`https://valm.qq.com/hero.html`。按玩家平台打开对应官网，找到目标英雄、皮肤、卡面、喷漆或挂饰的资料页、版本公告或活动页。已有来源链接直接复用；否则定向搜索 `site:val.qq.com 对象 款式` 或 `site:valm.qq.com 对象 款式`。端游国际官网 `playvalorant.com` 可作补充，名称与国服款式须核对。

## 取得参考图

1. 核对页面标题、平台、对象和款式。英雄选择目标角色后确认名称与立绘，默认示例图只作页面占位。
2. 从页面实际加载的目标图片取得原图链接，可查看 `src`、`data-src`、`srcset` 或公开网络响应中的图片字段。相对路径按页面 URL 解析，`//` 地址补 `https:`。静态页面只有占位内容时，用浏览器查看已加载的图片与网络响应。
3. 图片地址和对象 ID 以本次对应平台页面为准。端游与手游的数字 ID 分开使用，仅凭编号或文件名不能确认图片对象。
4. 用现有下载能力 GET 原图并跟随重定向，保存到本次任务 `.wip/input/`，记录来源页与图片链接。按实际文件格式打开看图，确认主体、款式与完整度；手游官网部分立绘带文字及特效背景，按玩家需求确定保留范围。
5. 公告只有长图时，先看整图确定对象位置，再按实际像素坐标裁出主体，保留原长图与来源。裁图保留关键形状，并核对附近其他道具。

官方来源由游戏官网页面及其引用图链共同证明，图片域名本身只作线索。页面访问失败、当前环境无法读取动态内容，或检查后没有所需图片时，进入主技能第三级通用联网搜索。仍缺少可用图时，请玩家提供图片，或按主流程征询文生图意愿。
