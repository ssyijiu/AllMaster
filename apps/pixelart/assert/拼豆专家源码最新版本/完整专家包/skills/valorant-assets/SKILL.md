# 无畏契约素材取图

## 目标与关联

本技能负责找到与玩家需求匹配的图片，核对具体对象与款式，再取得可使用的真实参考图。名称、图片及发布页面都可以作为核对依据。需要理解技能设定、社区梗或人物关系等文字信息时，按需调用 `无畏契约知识检索`；已有的知识结果、名称与来源直接复用，知识路径可选记录在 `--knowledge-id`。

先从玩家原话提取对象、平台和图片类型：英雄立绘、某款武器皮肤、指定炫彩、卡面或某种道具。默认端游 `pc`；明确手游、手瓦、源能行动时用 `mb`。「像手机的盘盘」中的手机描述外形，不单独作为平台证据。含义不明时先找候选并看图核对；仍有会改变选图结果的歧义，再补充知识或请玩家确认。

接口名称只用于定位候选。国服名称以本次接口、官方页面或可靠知识结果为准；外号与梗需有来源支持具体关联。搜索无命中时，拆开年份、战队、武器和系列关键词，用 `list` 核对相关类型的完整清单。主题下没有结果只说明该主题未匹配，需再核对武器与资产名，才判断当前来源是否提供所需素材。

## 取图策略

先判断需要准确游戏资产，还是创意参考、具体梗图或特定作品。准确资产按下列接口、官网、通用联网搜索顺序取图；创意参考与具体指涉可直接联网搜索，不以接口或官网失败为前提。可爱造型、有趣动作等原创表现可以由专家结合预设画风与经核实的角色背景设计，无需寻找现成的同姿势图片。

准确资产按平台与素材范围选择入口，成功取得且核对了所需图即可停止：

1. **接口直取**：端游素材先 `search` 或 `list` 找候选，核对英雄、武器、系列、年份和图片类型后 `get`。接口故障、清单核对后仍无该素材、或所需图片下载失败，进入官网。当前接口只有端游图片，手游直接进入第二级。
2. **官网**：按 `references/official.md` 定位对应平台的官方资料页、版本公告或活动页，从页面实际加载的图片中取得原图并核对对象。官网图片或页面足以确认对象时，直接使用该证据。
3. **通用联网搜索**：官网没有所需图片或访问失败后，搜索玩家对象、款式与平台，查看来源页面并核对图片。优先官方发布、游戏内截图及真实非 AI 玩家作品。

每级失败只表示当前来源未能提供所需图，不表示游戏中不存在。找到候选但款式、年份或平台不符时继续找；数量不足时如实说明，不用同系列的其他对象补齐。二创梗图、现实物品等超出接口范围的素材，从适用的官网或联网入口寻找。

联网选图时查看来源页面并打开图片，核对主体与创作需求，优先真实非 AI 玩家作品、官方卡面和游戏截图。具体梗、名场面或特定作品以对应原图、原始画面或玩家指向的作品为依据；文字含义或角色身份核实不等于找到视觉出处。尚未找到对应画面时继续查找或请玩家提供图片、链接，不用立绘配猜测描述替代。创意参考则检查动作、神态、构图与小尺寸辨识度，找到正确角色并不自动满足创作需求。

## 接口命令

使用安装目录脚本的绝对路径：

```bash
python3 <valorant-perler技能目录>/scripts/val_perler.py search assets search "捷风" --type 英雄 --platform pc
python3 <valorant-perler技能目录>/scripts/val_perler.py search assets list --type 英雄 --filter 捷风 --platform pc
python3 <valorant-perler技能目录>/scripts/val_perler.py search assets get add6443a-41bd-e414-f6ad-e58d267f4e95 --platform pc --out .wip/input --max 1
```

`search` 检索资产字段，返回 `found` 与 `results[]`（类型、uuid、资产名、图链；皮肤另有武器、品阶和系列）。空结果的 `next` 指向清单核对与降级步骤。`list` 列出英雄、皮肤、主题、地图、喷漆、卡面、挂饰，英雄优先；`--filter` 在清单内再筛，`--limit` 默认 200、`0` 不限，`total` 与 `truncated` 标明是否截断。核对完整清单时使用 `--limit 0`。

`get` 按 uuid 下载，`--max` 指定图数，返回 `saved[]` 与可选 `failed[]`。以保存的字段是否符合需求判断成功，其他字段下载成功不能替代所需字段失败。三个命令的 `--knowledge-id` 可选，`platform` 与知识路径用于保留上下文。接口缓存 24 小时，`--refresh` 重拉，`--offline` 只用缓存定位；下载仍需联网。

接口端点、uuid 和常用值见 `references/ids.md`（只存英雄、武器、品阶这类稳定的技术对应，不抄全量清单）。全部武器皮肤名称与品阶不落盘：需要核对完整清单时现场跑 `list --type 皮肤 --limit 0`（或按 `--filter` 细筛），以接口实时结果为准，具体系列与年份由候选及来源证据核对。

## 选图与完成

玩家上传的图优先。取得的参考图先给玩家确认，再用于生图；专家说明「随机」两路例外，抽中的立绘或皮肤本体图不展示、不等确认，直接用作生图参考。一次只用一张，英雄通常选完整立绘，皮肤通常选本体渲染图，具体以玩家要的形象为准。图片下载到本次任务 `.wip/input/`，按实际文件格式打开看图，核对主体、款式、平台和完整度，并保留来源页面及图片链接。

完成条件：图片可打开，确实是玩家要的对象与款式，来源可回溯；创意参考贴合本次动作、神态或构图需求，具体梗或作品已核对对应视觉内容。只能找到候选时说明待确认的差异；仍找不到可用图时，请玩家提供图片，或按主流程征询是否改做文生图原创方案。文生图不代替尚未完成的具体梗或作品核实。后续生图与交付按专家说明执行。

向玩家使用已核实的国服名称，直接展示符合需求的图；取图命令、uuid 与执行过程留在执行侧。
