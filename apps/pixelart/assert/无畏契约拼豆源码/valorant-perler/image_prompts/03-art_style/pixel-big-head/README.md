# 像素大头小图

玩家要“像素大头”“大头小图”“像素头像”这类大头加两颗小手的小像素头像时，选 `--art-style 像素大头小图`。只用于人物。没有点画风时仍按还原处理。

`art_style.md` 是通用画法，`pixel_style.md` 是配套的像素化段（24 至 28 列大色块），`subject_description.md` 是未填主体时的保图描述。新建任务用本目录的 `pixel_style.md` 取代基础的像素化段，也不补默认的任务段；`pixel_style`、`task_mission` 显式填写时以填写为准。背景由生图参数保证。

## 生成参数：只出 36、52、78

这个风格的图案只有 24 至 28 列色块，104、156 格没有意义。运行一键命令时传 `--boards 36 52 78`，只预生成三档，图纸最大 78 格：

```bash
python3 scripts/val_perler.py generate .wip/原图/原图.png \
  --work-dir <work_dir> --prompt .wip/提示词/提示词配置.json \
  --task-name "<任务名>" --art-style 像素大头小图 \
  --boards 36 52 78 --default-size <36、52 或 78>
```

- 默认展示尺寸按专家「推荐尺寸」章节选，必须是这三档之一。
- 不用 `--target-size`：它会在指定边长之外附带相邻的大规格（78 会带出 104）。

## 每张图要写什么

只写 `game_knowledge`、`subject_description`、`image_analysis`、`composition` 里这个角色独有的部分，画法不重复：

- 头型：主头颅饱满。发髻、马尾、帽子、兜帽这类部件贴合头颅，只略微探出轮廓，不竖成独立高塔；长度和方向写具体，高颅顶与部件高度分开写。
- 头发与脸：发际线、分缝、刘海方向、发色档数，肤色、瞳色、领口主色，标志配饰（发夹、耳环、护目镜、眼镜、胡子）的位置。
- 机器人、面罩、兜帽角色：写头壳或兜帽剪影，以及面罩屏幕或发光纹路的位置，不写皮肤与人类眼睛。
- 颜色：皮肤、兜帽、头发等大面积色块各指定一种色板里的明确颜色，写出十六进制色值，区域内部整块一致；不写夹在两颗豆色之间的中间色，否则同一块会被拆成两种豆，出现纵纹和杂斑。
- `composition` 只补站位，不改大头比例；默认不加背景，背景由生图参数保证。

画完先看 36 格：头部剪影、眼睛、标志配饰认得出来再交付。
