# 拼豆标准色号表（近似参考）

> ⚠️ 本表为拼豆配色参考用的**近似色**，HEX 值与色号对应关系仅供参考，实际下单 / 拼装请以 **Artkal、Hama、Mard 官方色卡**为准。不同品牌、不同豆型（2.6mm / 5mm）色号体系不同。

## 常用豆型与板子

| 项目 | 5mm 融合豆（常用） | 2.6mm 迷你豆 |
|------|-------------------|--------------|
| 品牌 | Artkal S 系列 / Hama Midi / Perler | Artkal C 系列 / Hama Mini |
| 常用板子 | 29×29、50×50 方形板 | 同左 |
| 单颗尺寸 | 约 5mm | 约 2.6mm |
| 适用 | 挂件、摆件、杯垫 | 精细图案、胸针 |
