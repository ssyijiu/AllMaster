# 游戏知识怎样约束生图

专家每次任务现写 `game_knowledge`，知识来源是 `valorant-knowledge` 技能（联网查角色/武器/皮肤信息）。这个目录不存档案，只放几个典型案例，说明没有这段知识时模型会怎样出错。

## 名字歧义改色

玩家说「做一个紫金爪刀的拼豆图纸」。参考图是金白配色的 Prime//2.0 爪刀，但名字里有「紫」。

没有知识约束时，模型看到「紫金」就把刀身改成紫色。v1 的 game_knowledge 里写了「升级状态下刀刃呈现皇家紫色能量质感」，进一步误导了模型。

v2 的写法在 game_knowledge 里先声明：

```
社区俗称「紫金爪刀」——注意「紫金」只是这套皮肤的中文叫法，
参考图里这把刀金白配色的样子就是它在游戏里的真实外观，没有紫色刀身。
```

再在 image_analysis 里补一句「不要因为名字里有紫字就把刀身改成紫色」。两段配合，模型才按参考图的真实配色画。

写法技巧见 `prime-karambit-name-color.md`。

## 梗图精髓保留

玩家发来一张捷风的游戏内 3D 模型截图，脸是低多边形建模，五官粗糙、眼神呆滞，配文「颗秒」。这张图好笑就在它的粗糙。

没有知识约束时，模型把它当成「质量不高的捷风图」，自动修成精致的动漫风小人，梗没了。

v2 在 game_knowledge 里写明笑点在哪：

```
这张图的笑点全在「粗糙又理直气壮的呆滞脸」。
画的时候必须保住这种低模粗糙感，画精致了梗就没了。
```

配合 subject_description 里「把参考图当平涂画原样描，不美化」，模型才保住梗。

写法技巧见 `04-subject_description/jett-lowpoly-meme.md`。

## 技能与动作重建

玩家说「我想要一个跳起来右键打闪光很搞笑的火男」，没给图。专家从官网拿到站姿立绘当参考。

没有知识约束时，模型不知道 Curveball 是什么、右键是什么意思、火球长什么样、飞行轨迹是什么弧线。

v1 在 game_knowledge 里写了技能机制：

```
他的招牌技能是 Curveball（曲线球闪光）：手里凝出一颗发光火球，
按右键向右侧弧线甩出，把角落里的敌人闪白。
玩家圈的梗是火男打闪时总爱耍帅、表情欠揍。
```

有了这段，subject_description 才能准确描述「右臂向右上方甩出，手里的闪光火球正脱手飞出，身后拖一道橙色弧线轨迹」。

写法技巧见 `06-image_analysis/phoenix-jump-flash.md`。
