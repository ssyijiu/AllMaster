# 拼豆图纸工具包 · 快速上手

这份工具包就是图纸制作流程的完整源文件：你可以在自己电脑上跑通「参考图 → 像素底稿 → 色号矩阵 → 交互图纸页」整条链路。

## 环境准备

```bash
pip install requests Pillow numpy opencv-python scikit-image scikit-learn
```

## 三步跑通一条最小链路

### 1. 写提示词配置

新建 `提示词配置.json`，填四个段落（写法详见 `image_prompts/像素图生成.md`）：

```json
{
  "game_knowledge":      "这是谁、有什么辨识点（非游戏角色就写参考图里的形象）",
  "subject_description": "画成什么样：部件颜色归属、五官结果、比例",
  "image_analysis":      "参考图保留什么、舍弃什么",
  "composition":         "主体怎样放进方形画布，主体外透明"
}
```

### 2. 拼出完整提示词，通读检查

```bash
cd valorant-perler
python3 scripts/val_perler.py generate <参考图.jpg> \
  --work-dir <工作目录> \
  --prompt <提示词配置.json> \
  --subject character \
  --task-name "任务名" \
  --prompt-only
```

- `--subject`：人物/角色用 `character`，武器挂饰等物品用 `prop`
- 检查生成在 `<工作目录>/.wip/提示词/提示词.md` 的全文，确认画风与内容一致

### 3. 正式出图纸

去掉 `--prompt-only` 再跑一次（约 40–60 秒）：

```bash
python3 scripts/val_perler.py generate <参考图.jpg> \
  --work-dir <工作目录> \
  --prompt <提示词配置.json> \
  --subject character \
  --task-name "任务名"
```

产物在 `<工作目录>/output/【拼豆专家】任务名-时间.html`，单文件、离线可开。
可用 `.wip/评审/尺寸对比.png` 核对各档（36/52/78/104/156）的五官细节，再决定
`--default-size` 推荐档；想只要某一档加 `--boards 52 78` 这样列出来。

## 常用参数速查

| 参数 | 作用 |
|---|---|
| `--art-style 贴纸 / Q版 / 柔彩手绘 / 手绘头像` | 换画风（默认还原） |
| `--target-size 52` | 玩家指定板子尺寸（15–156） |
| `--default-size 52` | 页面默认打开的推荐档 |
| `--render-size 1024x1536` | 竖幅构图时用 |
| `--merge-close-colors` | 归并近色，清理脸部杂色花斑 |
| `--edit "<修改要求>" --confirmed "<认可原话>"` | 在已认可底稿上做局部修改 |
| `--skip-gen --effect-image <底稿.png>` | 跳过生图，直接用现有底稿切格出图纸 |

## 生图服务说明

底稿生图走团队渲染服务 `https://val-perler.qq.com`，脚本自动带上本机的
WorkBuddy ID（取自 `~/.workbuddy` 个人配置目录），无需额外凭据。
服务不可用时脚本会报出失败步骤，等一会儿重试即可。

## 提示词怎么写好（三句话版）

1. **先定看点**：这张图最值得保留的一个特质，写进最前面的段落。
2. **按部件写颜色归属**，不写抽象形容词："深棕头发与浅棕刘海要有明度差" 好过 "层次分明"。
3. **五官写结果**："两颗黑色竖椭圆豆豆眼，微斜，无高光" —— 不要罗列画法禁令。

详细的反例和技巧都整理在 `image_prompts/像素图生成.md`，照着示例抄结构最快。
