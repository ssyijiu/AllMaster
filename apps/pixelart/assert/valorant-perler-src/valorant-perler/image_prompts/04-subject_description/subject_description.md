## 人物主体描述

参考图中的角色是一个无畏契约（VALORANT）游戏人物。身体比例、脸型和线条风格按 `<art_style>` 的画风来画。

核心特征需要保留：
- 发型、发色、头饰等视觉锚点
- 面部表情（眼睛和嘴巴需要足够大，缩成拼豆图纸后仍能看出眼睛朝向和微笑/严肃/惊讶等表情）
- 服装的整体色块划分（不用追求布料褶皱，但要能分出上衣、下装、外套、配饰的不同颜色区域）
- 人物动作姿态的身体语言（站姿、坐姿、施法动作、双手位置）
- 原图中如果人物身上有明显的标志性饰品或道具（耳机、腰带、背包、武器、法球等），需要保留位置和色系

构图策略是"紧凑但完整"：人物尽量充满画面，但也不能为了铺满画面而牺牲动作的可辨识度。如果动作是全身性的（蹲、跳、挥拳），宁可缩小人物也要让动作轮廓清楚。

人物以外的区域保持透明。身上各部位按拼豆底稿的颜色规则画：一个部位以一种平涂色为主，相近色差并入同一个颜色，只有色差肉眼明显且是造型本来就有的对比时才用第二种颜色。
