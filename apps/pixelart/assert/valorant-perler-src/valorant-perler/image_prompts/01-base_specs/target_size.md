## 这次只做一张 {N}×{N} 的小图纸

玩家指定了板子尺寸：这张图只会变成一张 {N}×{N} 的小拼豆图纸，整块板 {BEADS} 颗豆。上面说的「同一张图采样到五种板子、色块越多越细越好」这次不适用，以本段为准。

- 按这块小板子画：把画布想成约 {GRID}×{GRID} 的方格，每颗豆约对应 2×2 格，色块按这个粒度画，不要画一张细腻的图再等脚本缩小。
- 小板子靠轮廓认人：先保外轮廓剪影、动作姿态和两三个辨识锚点；内部细节放不下就整块省掉，不要为了保细节把轮廓画碎。
- 外轮廓用连续的深色勾边和透明背景分开；细长部件（手臂、尾巴、武器、发梢）加粗到连续不断，宁可加粗也不要断成散点。
- 颜色比平时更少，相近颜色合并。
