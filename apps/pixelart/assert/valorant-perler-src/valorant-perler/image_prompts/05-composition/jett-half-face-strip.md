# 构图重构：竖条半脸特写

默认人物描述按「紧凑但完整」处理参考图，全身立绘进来出的还是全身像，不会自己裁成半脸。要明确告诉模型：从哪里取材、舍弃什么，再从上到下分段写目标形态。

```text
参考图是<角色>的官方全身立绘（<姿态与服装一句话>）。不要照搬全身：从立绘头部取材，重新构图为一张竖长条形的半脸特写像素画，目标形态参照玩家社区流行的「书签式」拼豆作品：

- 整体是约 1:3 的竖长条，四周一圈黑色描边外框，居中放在画面里，竖条以外的两侧保持透明；
- 上半部：脸的半侧特写——<肤色>、一只大的<眼色>眼睛（<瞳孔>+白高光）、<眉>与<嘴>；<发色>头发从头顶披下；
- 中部：脸下方过渡到<衣领颜色>的衣领；
- 下部：肩膀区域用<主色系>交错色块收尾（类似格纹/迷彩的节奏）。

立绘里的全身元素（<腰带、武器等>）全部舍弃。
```

- 竖条比例、黑框、两侧透明这三点写在同一句，模型会当成一个整体形态来画。
- 上中下分段写，每段只写颜色归属和一两个辨识点，比整段描述更容易对上位置。
- 黑框不一定能在底稿里画全，下游描边会补齐，验收时看图纸，不要只看底稿。
- 写「半侧特写」时，模型容易画成正面半遮脸。想要侧脸，就加上视角说明：「脸朝画面<左/右>侧转约 45°，只露出靠近观众的半边脸和一只眼」。
