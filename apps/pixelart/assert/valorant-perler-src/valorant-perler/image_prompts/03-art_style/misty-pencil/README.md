# 柔彩手绘

玩家明确要“柔彩手绘”“粉彩手绘”“低饱和彩铅”时，选 `--art-style 柔彩手绘`。没有点画风时仍按还原处理。用于人像模板，非人像采用还原或玩家自定义描述；发型条款只作用于有头发的角色。

`art_style.md` 定义通用画法。先读取所选基础模板的主体和构图，将它们与玩家调整合成完整描述；未选基础模板时用 `subject_description.md` 的还原造型。脚本保留完整 `pixel_style`，此画风的新建任务不补默认 `task_mission`，避免其中的饱和色要求覆盖灰雾配色。背景由生图参数保证，不在任务段里再写。主体仍需先经生图转为像素图案，再出图纸。

动作与画风的执行规则见主技能 `SKILL.md`「柔彩手绘：画风与动作分开」。

## 每张图要定制什么

- `game_knowledge`：角色身份和可核对的辨识点。发型写刘海有无与方向、长短、分缕走向、马尾或发髻位置；颜色写各部件的色相归属、挑染位置、肤色、瞳色和标志饰品。有参考图就对照图，拿不准的查文字知识或请玩家补图，不凭印象填。
- `subject_description`：具体比例、表情、手势、道具和配饰。只改玩家要求改的部分；灰雾是配色画法，不等于统一脸型或统一发型。
- `image_analysis`：分清参考图保留的角色辨识点与玩家要改变的动作；本次新动作优先于参考图姿势。转画风时不追加写实比例锁定。
- `composition`：大头、半身或全身，主体朝向、位置与完整入画范围。大头不补身体，全身不自动裁成大头。

色相是否仍属于原图那一类，要对照生出的图检查；不能因灰雾感成立就宣称角色配色准确。外圈贴纸边只在玩家明确要求时写入主体描述。

## 可选：哭哭大头

只有玩家要“哭哭大头”或委屈要哭的头像时，才将下面的模板填进 `subject_description`；将 `{道具}` 换成本次确认的道具，无道具时改成小手放在下巴下方。不要把模板变量原样交给生图。

```text
Q 版大头，只画头和下巴下方一对小手。脸小而圆，位于头的下半部分，两颊鼓出圆圆的肉包。头部外轮廓按本次角色发型画，不用共用头型覆盖角色剪影。
两只又大又圆的横向椭圆眼睛完全睁开，上眼线向上拱，外眼角甩出两根短睫毛。眼睛内部是一整块平涂的瞳色，没有深色瞳孔或星星高光；下半部分有一条横向白色宽带表示蓄满眼泪，下眼睑中间挂一颗小白泪珠，泪水不往下流。眉毛是下垂的八字短线，表情委屈要哭。
两颊各一块粉色腮红，上面叠三四道竖向红色短线。嘴小而张开，粉色圆角倒梯形。下巴下方两个圆团小手，没有手指，捏着{道具}。
```

若玩家要其他表情，直接按他的表情写主体，不加载哭哭模板。肤色、瞳色、发型、道具与是否带贴纸边始终逐图定制。
