## 还原参考图（人物 / 动物 / 器物 / 插画通用）

保持参考图主体本身的身份辨识点、造型比例、线条风格、材质区分和整体配色，按原样还原：**不要改成 Q 版、大头短身或卡通化处理，也不要随意增减主体部件。**

- 人物：保留脸型、五官画法、发型、服装主色与主要剪裁、配饰与标志；保持成熟体态与原有动作姿态。为使小规格图纸上的五官可辨，必要时将头部连发型轻微放大，放大量约 25%，但绝不改成大头短身体。
- 动物：保留品种毛色、斑纹、耳型、眼型与神态；四肢、尾巴、爪子都要完整画全，保持真实体态与比例，不要拟人化也不要缩短四肢。
- 器物 / 插画角色：保留造型比例、主要结构、纹样与配色；身上的标志性道具要完整保留位置和色系。

构图与取景按 `<composition>`：主体的每一部分——头 / 身 / 四肢 / 尾巴 / 长道具——都必须完整落在画面内，不被边缘裁掉；长道具（棍棒、伞、法杖、长枪等）横贯或斜穿画面时两端都要入画。手中或身边的标志性道具按 `<image_analysis>` 与本次要求取舍，未指定时沿用参考图。画法按 `<art_style>` 的画风。
