# 人像模板与画法库

模板将画法、默认造型和取景组合成一个创作起点。菜单仅在人像状态显示；人像包括真人、人物、机器人与其他人形角色。玩家可以在图纸页「是否人像」更正初始判断。非人像用 `--subject prop`，默认还原，也可将自行描述的画法作为 `--art-style` 传入。

| 画风 | `--art-style` 写法 | 适用对象 | 默认效果 |
|---|---|---|---|
| 卡通（人物默认，原「官方同款」） | `卡通` | 人像 | 三头身小人人形模板：统一粗深色描边、五官色块化、高饱和硬边明暗两档、少色数好拼、无道具无背景 |
| 还原（道具默认） | `还原` | 所有主体 | 保留原画法、体态与动作，简化细碎服饰和光影；人像必要时轻微放大头部 |
| 像素大头 | `像素大头小图` | 人像 | 紧凑探头头像，下沿左右各一颗小手 |
| 贴纸 | `贴纸` | 人像 | 正面静态大头小身体，胸前圆点手和短脚，黑豆眼与小ω嘴 |
| 手绘头像 | `手绘头像` | 人像 | 粗圆线平涂，胸上大头、大眼和明确表情 |
| Q版 | `Q版` | 人像 | 约两头身，保留原角色画法、服装层次和标志配饰，通过比例与表情变可爱 |
| 柔彩手绘 | `柔彩手绘` | 人像 | 保留基础造型与动作，转低饱和灰雾配色和松散深灰线 |
| 自定义 | 按 `画风定义.md` 扩写的描述 | 所有主体 | 玩家自行描述的创作要求 |

每次加载一个 `art_style.md`。画法只负责线条、五官画法、上色和质感；造型与比例由 `subject_description.md` 承担，取景由 `composition.md` 或本次构图承担。玩家显式填写主体或构图时整段替换默认描述，先读默认配方，再合成保留未修改维度的完整最终描述。

手绘小人、简笔小人和手绘表情包归入Q版，不单独列卡。贴纸与像素大头是固定形态；要改成完整身体动作时采用Q版，胸上手势采用手绘头像。遮脸角色与机器人保留自己的遮挡物和发光标识。

像素大头读取 `pixel-big-head/README.md`，运行传 `--boards 36 52 78`。手绘头像和像素大头自带 `pixel_style.md`，新任务不补默认任务段。柔彩手绘读取 `misty-pencil/README.md`，将所选基础模板的主体与取景合成完整描述；未指定基础时采用还原。柔彩保留完整像素要求，不补默认饱和色任务段。

局部修改 `--edit` 沿用输入底稿；换模板用真实参考图新建图稿。菜单及复制话术在 `assets/style_guide.json`，运行叫法在 `scripts/gen_and_recover.py` 的 `ART_STYLES`。
