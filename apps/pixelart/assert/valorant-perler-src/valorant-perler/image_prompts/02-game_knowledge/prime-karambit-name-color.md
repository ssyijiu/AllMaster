# 名字不改色

皮肤名里的颜色字眼（「紫金」「赤红」）会把模型往那个颜色拉，参考图明明是金白，画出来却成了紫色。在两处说清楚：

```text
game_knowledge：社区俗称「<名字>」——注意「<颜色字>」只是这套皮肤的中文叫法，参考图里<实际配色>的样子就是它在游戏里的真实外观。

image_analysis：这张图本身就是目标的最终样子，造型、比例、配色全部照搬保留，一个部件都不改色。不要因为名字里有「<颜色字>」字就把<部件>改成<颜色>——参考图上没有<颜色>，成品里也不应该出现。
```

`subject_description` 只写相对参考图的保真要求（部件结构、色块合并、加粗），不写具体颜色名，免得和参考图打架。
