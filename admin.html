管理员登录

使用与前台相同的账号登录。只有站长绑定的管理员账号可以编辑配置；API Key 存放在独立的密钥表中，未登录的访客完全无法读取。

说明：服务商 API Key 与风格配置分开存储——Key 只在登录后经加密通道读取， 且仅用于生成时调用对应服务商；匿名访客与未登录会话读不到任何 Key。

无管理权限

当前登录账号不是本应用的管理员。如需管理权限，请联系站长在后台配置中更新管理员账号。

AI 服务商

配置各家的接口地址、API Key 与图像模型。风格通过「绑定的服务商」决定用哪家的 Key 与模型生成。Key 保存后不再回显，留空表示保持不变。

风格列表

每种风格 = 名称 + 封面图（可上传）+ 提示词（可留空）+ 绑定的服务商。提示词留空时，前台会把用户填写的「补充描述」作为提示词发送给 AI。

积分与订单

积分账本存于云端数据库，余额由全部流水派生、不可篡改。此处可手动充值、生成兑换码、同步线上支付订单（入账幂等，重复操作不会重复加）。
