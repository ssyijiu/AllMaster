管理员登录

只有管理员白名单里的邮箱可以登录本后台：白名单外的邮箱连验证码都发不出去。API Key 存放在服务器，页面只显示「是否已配置」，从不回传明文。

说明：服务商 API Key 只存在服务器本机（.ai-config.json，权限 600）， 后台只能写入新 Key、看到「已配置/未配置」，读不到明文。 管理员身份由 ADMIN_EMAILS 环境变量或 .admin-config.json 的白名单决定。

禁止访问

该邮箱不是本后台的管理员，已被拒绝访问。后台只接受白名单内的管理员邮箱登录。

AI 服务商

配置各家的接口地址、API Key 与图像模型。风格通过「绑定的服务商」决定用哪家的 Key 与模型生成。Key 保存后不再回显，留空表示保持不变。

风格列表

每种风格 = 名称 + 封面图（可上传）+ 提示词（可留空）+ 绑定的服务商。提示词留空时，前台会把用户填写的「补充描述」作为提示词发送给 AI。
